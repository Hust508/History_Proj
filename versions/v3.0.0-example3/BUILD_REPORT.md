## 源码与功能核对

- 基于用户提供的最终版例程一 ZIP 创建新工程，232 个原有源文件、IP 与约束文件逐字节相同；改动原有 HDL 仅顶层插入 OSD 和参数。
- 采集仍为 SC500CS 1280×720，ISP 仍为去马赛克和白平衡；DDR 保存完整图像，显示取中心 1024×600。新增 OSD 不参与摄像头采集和 DDR 写入。
- 例程三的 `osd_char_lib.v` 原样复制。Logo 全部 25600 个 alpha/RGB 值与原稀疏 case 表一致，包括 6387 个不透明像素；改为同步 ROM 减少组合逻辑。
- 综合日志确认读取新的 `anlogic_logo.hex`，并保留例程一的 `config_data_panel7.mif.dat` 面板初始化。
- 三份 TD 工程及运行描述共 204 个相对源文件/IP/约束引用均存在；Logo 初始化文件在两个运行目录下均能解析。
- 本目录与另一目录中的工程副本都已用 TD 成功打开。源码来源、输入 ZIP 哈希见 `SOURCE_PROVENANCE.json`；原有文件哈希见 `UNCHANGED_BASE_SHA256.json`。

设计文档中“摄像头 1024×600”“Sobel 阈值”和边缘滤波条目与实际例程内容存在出入。本实现依据最终版例程一和例程三实际 Logo/字模/计数实现，输出原始彩色实时图像与 OSD。按键功能保持原代码的复位及模拟增益控制。

## RTL 动态仿真

使用 Vivado Simulator 2025.1 执行实际新增 Verilog。参考模型以原始字模行数据和位图像素为输入，独立计算布局与缩放，逐拍比较 RGB、DE、HS、VS。

OSD 仿真通过 4934690 个时钟检查、2546688 个有效像素；同时比较默认参数、禁用 OSD、移动位置并改变文字颜色三种配置。包括：

- 多个 1024×600 完整帧，含 1344 时钟行周期，以及较短消隐压力测试。
- Logo 不透明区、Logo 透明区、中文、CNT 冒号、六位数字及其他原图区域。记录到 29067 个 Logo 替换像素、3708 个文字替换像素和 2513913 个未改变的视频像素。
- 1 拍、2 拍、24 拍和 64 拍等 VSYNC 脉宽；计数按上升沿每帧只更新一次。
- 在第 87 行后中断画面并复位，随后重新输出完整帧。
- 连续 1000000 次帧计数触发，覆盖所有十进制进位和 999999 回零。

另外运行原例程二工作中已建立的裁剪地址测试，覆盖四个 DDR 帧缓存、读请求停顿、31 拍返回延时、帧中断重启与 600 行边界。该测试使用简化 FIFO，仅验证地址和请求控制，不宣称验证了真实 DDR/FIFO 数据链。

`verification/osd_preview.png` 为本次 RTL 仿真产生的 1024×600 图像，已查看 Logo、文字和透明背景效果；它不是开发板截图。可重新运行 `verification/run_sim.ps1` 复现验证。
