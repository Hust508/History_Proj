## 本次执行的验证

- TD 从 `.al` 工程打开并成功分析 101 个源码文件；独立的综合及物理 run 配置均已构建。
- 3 份 `.al` / `.prj` 文件共 198 个相对源码、IP、约束引用全部存在，未依赖原 ZIP 所在桌面目录。
- 使用 Vivado Simulator 2025.1 对实际 `edge_detect_96.v` 与 `data_96bit_to_128bit.v` 做 RTL 动态仿真。参考值从独立的二维灰度图像数组计算 Sobel，逐拍比较二值输出；打包使用字节流队列比较。
- 小尺寸 32×8：检查 2,656 个像素、664 个输入拍、498 个 DDR 字，覆盖黑/白平场、横/竖阶跃、棋盘、彩色纹理、渐变、斜向图案，阈值 80 和 500。
- 1280×720：6 个完整图案帧及两次截断帧恢复，共检查 7,375,392 个像素、1,843,848 个输入拍、1,382,886 个 128-bit DDR 字。分别覆盖 SOF 与首个有效拍重合、SOF 位于消隐期、行消隐及截断帧重启；两个阈值均逐拍通过。
- 对实际 `video_out.v` 做裁剪地址 RTL 动态仿真：四个帧缓冲区、读请求停顿、31 周期 DDR 返回延时、部分帧中断和 600 行边界均通过。此测试中的 FIFO 为地址测试桩，不代表完整 DDR/FIFO 像素链仿真。
- 离线几何检查覆盖四个缓冲区共 460,800 个裁剪读地址，并确认每行 320 个 96-bit 拍→240 个 128-bit 字、显示每行 192 个字→1024 个 RGB888 像素。
- 屏幕原始 COE→ROM→命令解析回环通过：50 个包、283 个有效 ROM 字节、全部参数和延时与最终例程一一致。
- 与最终版例程一相比，`user_source/` 中 231 个既有文件逐字节未变；仅顶层和 ISP 连接文件修改，另加入移植后的检测模块。校验值见 `SOURCE_PROVENANCE.json`。
